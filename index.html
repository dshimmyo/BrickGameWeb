Quick Start:

  • Press Z (A) or X (B) to select controller
  • Paddle Mode:
  • - click in the screen to capture the mouse
  • - press escape to get the mouse cursor back
  • Gamepad
  • use arrow keys to move left and right

Player 1 Controls:

  • Paddle (Mouse) Mode:
  • Z key = A Button
  • Enter = Start Button
  • Mouse left/right = Paddle left/right
  • Gamepad Mode:
  • Arrow Keys = Directional Buttons
  • Enter = Start
  • Z, X, C = A, B, C
  • B, N, M = also A, B, C

Player 2 Controls:

  • T,F,G,H = Up, Left, Down, Right
  • 1 = Start
  • Tab, Q, W = A, B, C
  • LShift, A, S = also A, B, C

General Keybinds:

  • R = Reset
  • Shift+R = Hard Reset
